# Атырау ауасы: иіс қайдан келеді?

Атырау облысындағы ауа сапасы бекеттерінің көрсеткіштерін (Қазгидромет картасы [ecodata.kz](http://ecodata.kz:3838/app_dem_visual/)) сағат сайын жинап, жел бағытымен салыстырып, күкіртсутектің (H2S) ықтимал көзін анықтайтын жоба.

- `collector/collect.py` — сағат сайынғы жинағыш (GitHub Actions, `.github/workflows/collect.yml`)
- `data/` — жиналған деректер: `stations.csv` (бекеттер), `wind.csv` (жел, күн радиациясы, бұлттылық — Open-Meteo)
- `index.html` — карта, сағат жылжытқышы, көзді анықтау
- `model.js` — Гаусс шлейфі моделі (шығарылым биіктігін ескереді), тесттер: `node --test tests/model.test.js`
- `sources.json` — ықтимал көздер тізімі (координат, биіктік)

Нәтиже — ықтималдық бағасы, кінәліні дәлелдеу емес. ТШО және NCOC бекеттерінің деректері өңделмеген (дереккөздегі ескерту бойынша).

## Әдістеме

Беттің төменгі жағындағы «📘 Әдістеме» бөлімінде толық жазылған: Гаусс шлейфі моделі (Пасквилл–Гиффорд тұрақтылық сыныптары, Бриггс σ формулалары, шығарылым биіктігі), деректер сапасын тексеру (тұрып қалған мәндер), шекті мәндер (ҚР ДСМ-70), көзді анықтау және тұрақты жоғары бекеттер.
